## 1. Алгоритм и блок-схема



### Алгоритм
1. **Начало**
2. Подключение необходимых библиотек:<br>
   - `stdio.h` - для ввода/вывода<br>
   - `locale.h` - для поддержки русского языка<br>
   - `math.h` - для математических функций
3. Установка русской локали
4. Создание переменных:<br>
   - `ch` - символ для отрисовки треугольника (тип char)<br>
   - `size` - размер стороны треугольника (тип int)
5. Ввод значения `size` и символа `ch` с клавиатуры
6. Установка начального значения счетчика `i = 1`
7. Начало главного цикла с условием `i <= size`
8. Установка начального значения счетчика `j = 1`
9. Начало вложенного цикла для пробелов с условием `j <= size - i`
10. Вывод пробела на экран
11. Увеличение счетчика `j = j + 1`
12. Проверка условия `j <= size - i`:
    - Если условие истинно - переход к шагу 10
    - Если условие ложно - продолжение выполнения
13. Установка начального значения счетчика `j = 1`
14. Начало вложенного цикла для символов с условием `j <= (2 * i - 1)`
15. Проверка условий для отрисовки границ:
    - Если `j == 1` (левый край) - вывод символа `ch`
    - Если `i == 1` (первая строка) - вывод символа `ch`
    - Если `i == size` (последняя строка) - вывод символа `ch`
    - Если `j == (2 * i - 1)` (правый край) - вывод символа `ch`
    - Иначе - вывод пробела
16. Увеличение счетчика `j = j + 1`
17. Проверка условия `j <= (2 * i - 1)`:
    - Если условие истинно - переход к шагу 15
    - Если условие ложно - продолжение выполнения
18. Переход на новую строку
19. Увеличение счетчика `i = i + 1`
20. Проверка условия `i <= size`:
    - Если условие истинно - переход к шагу 8
    - Если условие ложно - продолжение выполнения
21. **Конец**

## 2. Реализация программы

```c
//Необходимые библиотеки
#include <stdio.h>
#include <locale.h>
#include <math.h>

// Основная функция

int main() {
	// Русская локаль
	setlocale(LC_CTYPE, "RUS");
	// Инициализация переменных
	char ch;
	int size;
	// Ввод размера стороны и символа равностороннего треугольника с клавиатуры
	printf("Введите размер стороны равностороннего треугольника и символ, из которого будет состоять фигура: ");
	scanf("%d %c", &size,&ch);
	getchar();
	// Цикл построения фигуры
	
	// Главный цикл
	for (int i = 1; i <= size; i++) {
		// Цикл для пробелов (чтобы фигура была в центре)
		for (int j = 1; j <= size - i;j++ ) {
			printf(" ");
		}																							// На примере size == 4, i == 3
		for (int j = 1; j <= (2 * i - 1); j++) {// Цикл расстановки символов						// Сначала j == 1, то есть после пробелов ставится символ(выполнилось одно из условий if)
			if (j == 1 || i == 1 || i == size || j == (2 * i - 1)) {								// Затем j == 2 - не выолняется ни одно условие if, ставится пробел
				printf("%c", ch);																	// j == 3, пробел
			}																						// j == 4, пробел
			else printf(" ");																		// j == 5, выполняется условие j == (2*i-1) ; (2*3-1) == 5, ставится символ 
		}
		printf("\n");										                                                        // j == 6, условие верхнего цикла перестает выполняться, цикл завершается
	}
	return 0;
}
```
